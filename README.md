# Studio Showroom

A first-pass interactive studio portfolio built with Vite + React + React Three Fiber.

## Run
1. Install Node.js 20+.
2. Open this folder in your editor.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Customize first
- Replace `studio°` with your final studio name.
- Replace `hello@yourstudio.in` with the real email.
- Replace the concept cards with real demo projects.
- Add real imagery/3D assets once the art direction is locked.
- Connect forms, analytics, domain and hosting before launch.

The current version intentionally avoids generic SaaS sections and uses 3D only in the hero so the experience stays premium and fast.
